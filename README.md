# Hydropower Predictive Maintenance

AI-powered predictive maintenance and anomaly detection for hydropower turbine systems using deep learning and time-series analytics.

## Overview

This repository contains machine learning and deep learning models developed for predictive maintenance of hydraulic turbine systems.

The project investigates the use of CNN, LSTM, and CNN-LSTM architectures for anomaly detection and condition monitoring using industrial time-series data.

## Repository Structure

### CNN Model
- Feature extraction and anomaly detection using Convolutional Neural Networks.

### LSTM Model
- Time-series modeling and predictive maintenance using Long Short-Term Memory networks.

### CNN-LSTM Hybrid Model
- Combined spatial and temporal feature learning for enhanced predictive maintenance performance.
